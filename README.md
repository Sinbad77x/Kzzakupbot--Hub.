# Kzzakupbot Hub

Flask-сайт: закупки РК, тендерный калькулятор, банки и гарантии, академия поставщика (каталог 20 источников, без цен).

Структура: `app.py` (маршрут `/`), `templates/index.html`, `static/css/style.css`, `static/js/main.js`.

Локально: `pip install -r requirements.txt && python app.py` (http://localhost:5000).
Render: Blueprint из `render.yaml` или Web Service, Build `pip install -r requirements.txt`, Start `gunicorn app:app`.

## Калькулятор (редакция 16.11.2026)

- СНР на основе упрощённой декларации: базовая ставка 4%, поле настройки в диапазоне 2–6%; налог считается с дохода, а не с прибыли.
- ОУР с НДС: базовая ставка НДС 16%; цена вводится без НДС, входящий НДС к зачёту задаётся вручную.
- ОУР без НДС: налог на расчётную прибыль задаётся отдельной ставкой КПН/ИПН.
- Минимальная комиссия банка задаётся отдельно. В калькуляторе она применяется к сумме двух обеспечений как упрощённая оценка; тарифы конкретных банков могут рассчитывать комиссии раздельно.
- Обеспечения отражаются как суммы гарантии/блокировки, а не автоматически как расходы.
- Модель ориентировочная: не заменяет налоговый расчёт и не учитывает все вычеты, налоговые корректировки, ограничения режима и социальные платежи.

Официальные налоговые ориентиры на дату проверки:
- КГД — СНР 4% и региональный диапазон 2–6%: https://www.gov.kz/org/kgd-vko/press/news/details/1288957?lang=ru
- КГД — НДС с 2026 года: https://www.gov.kz/org/kgd-abay/press/news/details/1115507?lang=ru
